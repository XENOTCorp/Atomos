Release `examples/first_app` on `127.0.0.1:8090`. RSS cap 64 MiB.

## Real rps (Rust loadgen)

The Python `http.client` run below is **client-bound** (~2–3k rps). Use
`examples/loadgen` (keep-alive + pipeline, std threads):

```bash
cargo run --release --example loadgen -- 127.0.0.1:8090 /api/health 8 3 8
```

Recorded 2026-08-21 **SOTA path: `engine=epoll`**, 4 pinned workers, **no**
H2/H3 in-process (those belong to `atomos-proto`). GET never takes the POST
mutex. Encoded-byte cache. `err=0` on every row. Observed VmRSS **2.98 → 3.22 MiB**.

H2/H3 are slower than pipelined H1 on loopback tiny JSON (frames + HPACK/QPACK
+ crypto). They work: `curl --http2-prior-knowledge`, `curl -k --http2`,
`curl -k --http3-only`. POST then GET shows the new note on H1, h2c, TLS h2,
and H3 (`after-h3` in the body).

64 MiB.

134k / 148k. Python `http.client` remains client-bound at ~2–3k rps — do not
use it for rps.

## How to read this

Same box as the server: Broadwell i5-5200U (2 cores / 4 threads), Python
`http.client` client. Numbers are **loopback HTTP/1.1 keep-alive**, not a
dedicated load generator. CPU % is process `utime+stime` over wall time
divided by 4 logical CPUs (so 15% of machine ≈ 0.6 of one logical core).
RSS/HWM from `/proc/<pid>/status`. 0 HTTP errors in every scenario.

Single-connection p50 ≈ 0.41–0.42 ms on all three GET paths (~2.1–2.2k rps).
Four concurrent connections raise throughput to ~3.0k rps and p50 to ~1.1 ms
(queueing). Eight connections do **not** add rps (~3.0k still) and p99
doubles to 8.1 ms — the 2-core accept/parse path is saturated.

`GET /api/health` is cached 1 s; 4000 serial requests take ~1.8 s so that run
is a mix of cache hits and misses, still slightly faster than uncached
`GET /api/notes`. After 200 POSTs the notes body is larger: serial GET notes
drops from 2142 to 1569 rps.

Idle RSS 3.37 MiB. Peak HWM 3.96 MiB after POSTs (cap 64 MiB). Five OS
threads (tokio runtime). Cooldown does not drop HWM (as expected).

Reproduce: `scripts/bench-first-app.sh 127.0.0.1:8090` (never 8082).
